# Summary
Generating prokaryotic assemblies has become standard procedure for many scientists and labs. However, generating the optimal assembly from the data at hand can be challenging and time consuming. Currently there are several pipelines available for prokaryotic assembly, where most of them only operate with draft and/or hybrid assembly, or only long-read assembly. Assemblage is a Nextflow pipeline designed to generate optimal assemblies by allowing the user to select the best track based on the data available. The pipeline has three assembly tracks; draft assembly, hybrid assembly, and long-read assembly. The draft track utilize Illumina short reads to generate regular draft assemblies with either Unicycler or SPAdes. The hybrid track utilize both short reads and long reads to generate hybrid assemblies. The long-read assembly track is designed around Autocycler, and utilize the power of consensus assembly for optimization of assemblies without requiring large amounts of manual work. Lastly, the optional Ellipsis subworkflow provides information on plasmids and resistance/virulence genes in the generated assemblies, essentially providing an all-in-one tool for assembly and genome characterization. Assemblage is available at https://github.com/NorwegianVeterinaryInstitute/Assemblage.

# Software design
The pipeline consists of three assembly tracks, and one subworkflow, namely draft assembly, hybrid assembly, long-read assembly, and Ellipsis. 

The draft genome track is used if the user only have Illumina short reads, and runs read quality control with FastQC before and after trimming with Trim-Galore, followed by an optional contamination check with Kraken2. Quality controlled reads are then downsampled with RaSuSa to a given coverage, before being assembled with either Unicycler or SPAdes and reorientation with DNAApler. The assembly is quality controlled with Quast and CheckM2, and actual coverage is calculated with BWA and Samtools. Lastly, MultiQC provides a useful report for all assemblies and quality control steps.

The hybrid assembly track is similar to the draft assembly track, but here Filtlong is run to filter out low-quality long reads. In the hybrid assembly step both short reads and long reads are used together to try to generate complete assemblies. Following assembly, the genomes are polished with Polypolish, followed by a QUAST comparison between the polished and non-polished assembly. Lastly, an html report is generated by MultiQC.

The last assembly track utilize the power of long reads to generate complete assemblies. This track is useful if the user have high-quality long reads.
