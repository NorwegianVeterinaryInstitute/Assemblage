# Summary
Microbial genomics is a rapidly developing field, and relies on accurate and high-quality genome assemblies. Generating these genomes may be challenging, as new tools and pipelines for assembly are increasing both in numbers and complexity. Currently, generating optimal assemblies is normally a tedious task which requires a lot of manual steps. Assemblage is a Nextflow pipeline desgined to make it easier to generate optimal assemblies, where the user can select tracks based on the data at hand. The pipeline consists of three assembly tracks, one for short-read data, one for short- and long-read data, and one for long-read data. The long-read assembly track is used for assembling high-quality long reads, and generates genomes based on consensus assembly with Autocycler without manual intervention. The pipeline also have a subworkflow for genome characterization and plasmid detection. The pipeline is available on GitHub at github.com/NorwegianVeterinaryInstitute/Assemblage. 

# Statement of need
Generating optimal assemblies have previously been a relatively manual process, with tools such as Trycycler [@Wick:2021] and later Autocycler [@Wick:2025]. While Autocycler was generated to be more automatic compared to Trycycler, it still requires manual steps before the tool can run, such as generating assemblies from read subsets using different assemblers. Assemblage utilize Nextflow [@DiTommaso:2017] to make this process automated, essentially allowing the user to do all steps required in the Autocycler process with one command. Further, the draft- and hybrid assembly tracks are easily available within the same framework, making it easy to generate assemblies with different methods for comparison, which may be crucial when assembling genomes with plasmids present. 

# State of the field
Several prokaryotic assembly pipelines exist, some of which are hosted by nf-core [@Ewels:2020]. These include genomeassembler [@genomeassembler] and bacass [@bacass]. The genomeassembler pipeline is created to assemble only long-reads. The bacass pipeline allows for different assembly strategies similar to Assemblage, however, it only includes simple genome annotation. Assemblage includes both general genome annotation with Bakta [@Schwengers:2021] and more specific annotation and characterization tools such as MOB-suite [@Robertson:2018], AMRFinderPlus [@Feldgarden:2021], VirulenceFinder, and others, within the optional Ellipsis subworkflow. This provides an all-in-one package for complete genome reconstruction and characterization.

# Software design
The pipeline consists of three assembly tracks, and one subworkflow, namely draft assembly, hybrid assembly, long-read assembly (\autoref{fig:figure1}), and Ellipsis. 

The draft genome track is used if the user only have Illumina short reads, and runs read quality control with FastQC [@BabrahamBioinformatics:2018] before and after trimming with Trim-Galore [@Krueger:2023], followed by an optional contamination check with Kraken2. Quality controlled reads are then downsampled with RaSuSa to a given coverage, before being assembled with either Unicycler [@Wick:2017] or SPAdes [@Bankevich:2012] and reorientation with DNAApler. The assembly is quality controlled with Quast [@Gurevich:2013] and CheckM2, and actual coverage is calculated with BWA and Samtools [@Li:2009a]. Lastly, MultiQC provides a useful report for all assemblies and quality control steps.

The hybrid assembly track is similar to the draft assembly track, but here Filtlong [@Wick:2021a] is run to filter out low-quality long reads. In the hybrid assembly step both short reads and long reads are used together to try to generate complete assemblies with either Unicycler or SPAdes. Following assembly, the genomes are polished with Polypolish. Lastly, assembly quality control is done with Quast and CheckM2. Here too an html-report is generated by MultiQC.

If the user have high-quality long reads available, the long read assembly track will likely create the highest quality assembly. Here, Autocycler is used to generate subsets of the reads, which are assembled with four different assemblers, namely Canu [@Koren:2017], Flye [@Kolmogorov:2019], Raven, and MiniASM [@Li:2016]. Then Autocycler runs clustering before combining all contigs that pass quality thresholds. If the user also have Illumina data available, they can be used to polish the resulting assemblies. Lastly, assembly quality control is run with coverage checks, overall assembly stats, and CheckM2, followed by a html-report by MultiQC.

![Overview of the assembly tracks in Assemblage.\label{fig:figure1}](pipeline_overview.png)

Lastly, the Ellipsis subworkflow runs MOB-suite to classify/predict replicons as chromosomes or plasmids before running Bakta, Resfinder, Virulencefinder, PlasmidFinder, and AMRFinderPlus. Summarised text reports are outputted per tool, as well as one replicon-level report for all the results together. This report format makes it easy to identify potential genes of interest on specific plasmids. This is especially powerful coupled with the hybrid- or long-read assembly tracks, since these tracks are more likely to produce complete genomes.

# Research impact statement
Assemblage has become the standard method for generating prokaryotic genome assemblies within research at the Norwegian Veterinary Institute. Since its creation, it has been used in several research projects, as well as for outbreak investigations and surveillance.

Due to pipeline in nextflow, easily available for other systems and users.
